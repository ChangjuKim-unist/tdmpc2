# 이전 연구(SimDist)에서 가져올 것

이전 저장소: `~/simdist`(fork `ChangjuKim-unist/simdist`, branch go1-support). 문서는 `docs/designNN_*_ko.md`, 전체 기록은 `docs/research_log_ko.md`, 조사 보고서는 `reports/`(git 제외)에 있다. 필요할 때만 꺼내 쓴다.

## 왜 새 출발인가

- SimDist(Go1)와 장난감 MJX 환경에서 설계 20–43을 돌렸는데, 적응 방법은 대부분 실패했다. 요약: simdist `docs/toy_path_40_43_summary_ko.md`.
- 공통 원인은 planner가 학습된 모델의 틀린 곳을 골라 가는 것이었다. 평균 오차가 줄어도 이 문제는 남았다. 이를 문제로 직접 다루기로 하고, 기준 방법을 표준인 TD-MPC2로 바꿨다(2026-11-24 사용자 결정).

## 선행 연구 메모

- **TD-MPC2 자체도 value 오차가 크다.** 참 수익 대비 Dog-Trot 231 %, h1hand-run 2159 %. 계획 벌점을 넣으면 정규화 점수가 56.5 → 62.0으로 오른다. 출처: simdist `reports/월드모델 한계와 새 방법론 후보.md`.
- **겹칠 위험이 큰 연구.** offline RL의 비관적 방법(MOPO, MOReL), PIA, RACER, 앙상블 불확실성 벌점, 다단계 손실, DAgger식 모델 학습(Ross & Bagnell 2012). 새로움은 "적은 데이터 적응 + planner 악용 + 다리 로봇" 조합에서 나와야 한다.
- **관련 조사 보고서**(simdist `reports/`): 월드모델 로보틱스 문제점 지도, 적응형 세계모델 구조 아이디어 조사, 메타학습 동역학 적응 조사, MPPI 샘플링 분포 조사.
