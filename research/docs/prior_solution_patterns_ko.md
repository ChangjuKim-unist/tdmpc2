# 문헌조사: 선행 연구는 우리와 같은 문제를 어떤 기제로 풀었나 (2026-11-27, GPU 없음, 등록 안 함)

방법을 제안하려는 조사가 아니다. 다음 아이디어를 낼 때 쓸 직관을 얻으려고, 선행 연구가 "무엇을 무엇으로 바꿔서" 문제를 풀었는지를 모았다.

## 0. 한 일과 믿을 정도

- 네 갈래를 나눠 조사했다. 갈래마다 하위 조사 하나가 방법 절을 읽었고, 모두 합쳐 약 55편이다.
  1. 모델 착취와 모델·가치 섞기
  2. dynamics가 바뀔 때의 가치
  3. fine-tuning의 꺼짐과 망각
  4. 기준에서 안전하게 벗어나기와 권한 배분
- 하위 조사에는 우리 관찰을 사실로만 넘겼고, 제 해석은 넘기지 않았다.
- **원문에서 내가 직접 다시 확인한 주장 다섯:**
  - MVE §4.1과 그림 6: 정확한 dynamics를 써도 critic을 실제 분포에서만 학습하면 이득이 사라진다.
  - 2601.21306 부록과 한계 절: DMC에서는 Q 앙상블 최솟값의 효과가 거의 없다.
  - SGFT 정의 1과 "geometric insight": sim에서 갈 수 있는 다음 상태를 real에서도 만들 행동이 있어야 한다.
  - 잔차 정책 학습 §IV-B와 결과 절: actor에 비해 critic이 나쁘게 초기화되어 초반에 성능이 떨어지고, burn-in이 그 하락을 줄인다.
  - SOOPER 식 6–7: 사전 정책으로 넘어가는 지점에서 끝내고, 끝값으로 사전 정책의 비관적 가치를 준다.
- **검토 뒤 추가로 확인한 것(2026-11-27 저녁):**
  - MPQ(λ) 2012.05909 §3.1: 정리 3.1의 가정(모델은 전이와 비용이 α-근사, Q는 ε-근사)과 "작은 H와 부정확한 끝 가치는 MPC를 근시안적으로 만든다"는 문장.
  - SGFT 2502.02705 §4.2 알고리즘 3(MPC-SGFT): 사전학습 V_sim + 학습한 모델로 궤적 최적화, 실데이터로 모델을 다시 맞추는 고리.
  - SGFT 부록 C는 SAC 판의 구현만 적는다(실기 fine-tuning 때 critic을 무작위로 다시 초기화하고, V_sim은 얼려 보상 shaping에 쓰고, sim 데이터는 쓰지 않는다). TD-MPC2 판의 구현 세부(critic을 얼리는지, H 값)는 본문에서 찾지 못했다. 하위 조사가 적은 "TD-MPC2 판은 critic을 얼리고 H=4"는 **확인 안 됨**이다.
- **나머지는 하위 조사의 보고다.** 논문에 인용하기 전에 항목마다 원문과 서지를 다시 대조한다(RSS는 지어낸 인용을 desk reject한다).
- **못 한 것:**
  - arXiv 요청 제한 때문에, 여러 dynamics 모델을 온라인 가중(Hedge 계열)으로 섞는 MPC 논문은 찾지 못했다.
  - Kakade & Langford 2002, GAT 2017 원문은 arXiv에 없어 다른 논문 속 설명으로 대신했다.

## 3. 직관 셋

1. **우리 장치는 권한을 "전역적이고 고정된" 숫자로 줬다.** min, 평균, 검증 무게(0.65–0.71) 모두 그렇다. 문헌은 거의 모두 권한을 상태·행동마다 국소적으로 주거나(유형 C), 데이터에 맞지 않는 모델을 집합에서 뺀다(ARMOR). 우리 sim 모델은 바뀐 조건의 실데이터에 맞지 않는데도 모든 곳에서 거부권을 가졌다. 고정 규칙이 조건마다 갈린 것(설계 12)과 맞는 그림이다.
2. **sim 쪽이 도움이 된 이유는 비관이 아니라 "다른 오차를 가진 추정치를 섞은 것"이다**(min = 평균). 그렇다면 질문은 "얼마나 섞나"이고, 문헌의 답은 섞는 무게를 그 지점의 신뢰 신호로 정하는 것이다. 지평 섞기(A)와 국소 권한(C)이 같은 질문의 두 얼굴이다.
3. **가치 쪽에서 문헌이 공통으로 피하는 것은 "적은 데이터로 긴 지평 Q를 통째로 다시 맞추기"다.** 우리 설계 01, 03, 05가 바로 그것을 했다. 문헌이 대신 하는 것은 셋이다.
   - Q의 하한만 기준 정책의 실현 return으로 묶는다(Cal-QL).
   - 지지 밖으로 나가는 지점에서 끝내고 끝값을 기준 정책의 비관적 가치로 준다(SOOPER).
   - 정책이 critic을 따르기 전에 critic을 먼저 안정시킨다(burn-in, warm-up).
   우리는 이 중 어느 형태도 시험하지 않았다.

## 4. 심사에서 나올 위험

- **"sim 파라미터를 식별해서 다시 학습하면 되지 않나"(유형 F).** 우리 DMControl 변화(마찰, 질량, 모터)는 모두 sim 파라미터 집합 안에 있다. 이전 Go1 연구(`~/simdist` 설계 10–12)에서는 모터는 식별됐지만 마찰은 식별되지 않았다. 식별 기준선은 넣거나, 파라미터 집합 밖의 변화에서 차별점을 보여야 한다.
- **국소 권한의 신호.** 이전 Go1 연구 설계 30에서 오차 예측기, 거리, 분류기, 앙상블 불일치는 "지금 적응한 조건이 아니다"를 가리지 못했다(최고 0.75, 불일치는 오차의 1–4 %). 유형 C를 쓰려면 이와 다른 신호가 필요하다. SPIBB의 방문 수, H2O의 판별기, VGDF의 가치 일관성이 후보다.
- **SOOPER와의 거리.** 유형 D를 쓰면 SOOPER와 가장 가까워진다. 차이를 미리 적어야 한다.

## 6. 검토 뒤 고친 읽기 (2026-11-27 저녁, 외부 검토 의견 반영)

### 6.1 합의는 독립된 장치가 아니라 구성원 둘짜리 앙상블 벌점이다

- min(a, b) = (a + b)/2 − |a − b|/2 이므로, 합의 점수는 "두 상대 점수의 평균 − c × 불일치"에서 c = 0.5인 한 점이다. c = 0이면 평균이다.
- 그러니 벌점(FOWM)과 합의는 같은 족의 장치이고, 다른 것은 **앙상블에 누가 들어 있느냐**다. 벌점은 적응한 스택 안의 Q 다섯 개이고, 합의는 얼린 사전학습 스택과 적응한 스택이다. 방법의 새로움은 "얼린 사전학습 스택을 구성원으로 넣는다"로 좁혀진다.
- "조정이 필요 없다"는 주장은 성립하지 않는다. c = 0.5를 암묵적으로 고른 것이다.
- 항등식만으로는 "이득이 섞기에서 왔다"가 나오지 않는다. 실험 근거는 이렇다:
  - 정확한 dynamics 수준: c = 0(평균) 581, c = 0.5(min) 584, 차이 +3 [−10, +16](설계 11 A).
  - 학습한 모델 수준: c = 0은 설계 11 C에서 잰다. c = 0.5는 설계 10의 합의다.
  - 전부 고친 agent 수준(설계 12): c = 0과 c = 0.5의 순서가 조건마다 반대였다(quadruped 모터 593 대 643, walker 마찰 703 대 678).
  - c = 1은 아직 재지 않았다. c를 0, 0.5, 1로 바꾼 곡선을 보고해야 한다.
- 설계 10에서 같은 족의 두 점이 갈렸다. 적응 스택 안의 Q 앙상블 벌점(계수 1)은 해 없음에 실패했고, 얼린 스택을 넣은 합의는 통과했다. 구성원이 무엇이냐가 결과를 가른다는 근거다.

### 6.2 SGFT는 설명 도구가 아니라 가장 가까운 경쟁자다

- MPC-SGFT(알고리즘 3)의 계획 목적은 짧은 지평의 실제(학습 모델) 보상에 V_sim을 끝값으로 붙인 것이다. shaping된 보상 r + γV_sim(s′) − V_sim(s)를 H 스텝 합하면 Σγ^t r_t + γ^H V_sim(s_H) − V_sim(s_0)이고, 마지막 항은 후보에 무관하므로 **순위가 "H 스텝 보상 + 끝 가치"와 같다.** 우리 "장치 없음"(적응 dynamics + 얼린 Q, H = 3)은 MPC-SGFT의 배치 형태다.
- 그래서 223 < 408 < 584는 새 실패 모드의 발견이 아니라, **SGFT와 SimDist가 기대는 가정(정의 1: sim 가치의 순서가 real로 넘어온다)이 깨지는 조건의 실측**으로 써야 한다. 여전히 쓸모 있는 기여다.
- 설계 10에서 "장치 없음"은 cheetah 마찰(−312)과 quadruped 모터(−66)에서 해 없음에 실패했다. SGFT 구조가 이 두 조건에서 깨진다는 뜻이다. 다만 SGFT는 실데이터를 몇 시간 계속 모으며 모델을 다시 맞춘다. 같은 실데이터 예산으로 그 고리를 돌린 기준선이 필요하다. 설계 07의 "첫 라운드 모델만 쓰는 수집"이 두 라운드짜리 근사다.
- SGFT를 기준선의 맨 앞에 둔다.

### 6.3 직관 1(데이터에 안 맞는 모델을 뺀다)은 우리 결과와 충돌한다

- ARMOR식으로 실데이터 전이 적합도로 집합을 고르면 sim 스택이 가장 먼저 빠진다. 그런데 cheetah 마찰에서 584를 만든 것이 그 스택이다.
- sim 스택의 가치는 전이 정확도가 아니라 **모델과 Q가 서로 맞는다**는 데 있다. 국소 권한의 신호는 전이 적합도가 아니라 "return 순위를 얼마나 맞히는가"여야 한다.
- 신호를 찾기 전에 상한부터 잰다. 시간 구간이나 자세 같은 거친 단위로 섞는 비율을 달리 주고 폐루프 return으로 최적화했을 때, 가장 좋은 전역 고정 비율보다 얼마나 나은지 본다. 차이가 작으면 국소 권한은 병목이 아니다. 이 상한 측정이 좋게 나올 때만 국소 권한을 후보로 올린다.

### 6.4 "sim 파라미터를 식별해서 다시 학습"은 벤치마크의 문제다

- 우리 DMControl 변화는 모두 파라미터 하나이고, 10 에피소드면 식별될 가능성이 높다. 식별 뒤 고친 sim에서 다시 학습하는 것은 천장 측정과 같은 절차를 실데이터의 꺼짐 없이 하는 것이다. 이 시험대에서는 어떤 방법도 유형 F를 이기기 어렵다.
- 대응은 둘이다. (1) F를 기준선으로 실제로 돌린다. (2) 파라미터 집합 밖의 변화를 더한다(행동 지연, 액추에이터 저역 필터, 위치마다 다른 마찰 등, 래퍼로 넣을 수 있다). F가 정확히 고칠 수 없는 조건이 있어야 적응 방법이 필요해지고, Go1으로 넘어가는 다리도 된다.
- 방법을 고르기 전에 이것을 먼저 한다.
