# 설계 15: 전체 fine-tuning을 시작한 직후 Q는 어느 쪽으로 벌어지는가 (2026-11-27 등록, 측정만)

스크립트는 `research/scripts/d15.py`다.

## 0. 배경

- **관찰(설계 13 §10, 등록 안 함).** 사전학습 agent를 바뀐 조건에서 전부 fine-tuning하면 update가 시작된 직후 학습 return이 떨어진다.
  - quadruped 모터, 설계 07 §9의 실행: 566 → 482, 175, 123.
  - 설계 13의 작은 시험: 595, 578 → 223.
  - 같은 무렵 정책 손실의 Q 눈금(Q(z, π(z))의 5–95 백분위 폭)이 3 에피소드 사이에 6–8배 벌어진다(1.9 → 25.4).
- **선행 연구의 두 처방이 이 폭이 벌어진 방향에 따라 갈린다**(`research/docs/prior_solution_patterns_ko.md` 유형 E).
  - 위쪽으로만 벌어졌으면 과대평가다. 실현 return으로 하한을 묶는 형태(Cal-QL식)가 맞다.
  - 양쪽으로 퍼졌으면 불안정이다. critic을 먼저 안정시키는 것(burn-in, warm-up)과 sim 데이터 균형 샘플링이 먼저다.
- 외부 검토 의견(2026-11-27 저녁)이 다음 방법을 고르기 전에 이 측정을 권했다.

### 등록 전에 이미 본 값

위의 학습 return과 눈금 값, 그리고 §9 작은 시험의 값.

## 1. 질문

update 직후 Q가 벌어지는 방향은 위쪽(과대평가)인가, 양쪽(불안정)인가.

## 2. 고정 설정

- 조건: quadruped 모터 ×0.35, walker 마찰 ×0.15(설계 07 §9에서 둘 다 초반에 떨어졌다).
- seed 1, 2, 3(환경 seed 6000 + s, torch seed s).
- 시작 절차는 설계 13의 RAW와 같다. 사전학습 planner가 탐색 잡음을 켜고 5,000 스텝(10 에피소드)을 update 없이 모으고, 그 뒤 공식 online 학습(모든 구성요소, 환경 스텝당 update 1회)을 3,000 update(6 에피소드) 한다.
- 모델 snapshot: update 0(시작 전), 그리고 250 update마다.

## 3. 측정

- **고정 상태 집합.** 그 seed의 수집 에피소드 10개, 각 50–349 스텝(3,000개 상태, 출발 구간을 뺀 달리는 구간). 모든 snapshot이 같은 상태를 채점한다.
- **Q 두 가지.**
  - Q(z_t, π(z_t)): 정책의 평균 행동. planner의 끝 가치와 정책 손실이 쓰는 값이다.
  - Q(z_t, a_t): 실행된 행동.
  - 둘 다 Q 다섯 개의 평균이다(two-hot 역변환).
- **기준 return G_t.** 그 에피소드 끝까지의 할인 보상 합에, 마지막 관측에서 사전학습 Q(z, π(z))로 bootstrap한 값을 더한다. 모든 snapshot에 같다.
- **snapshot마다 기록:** 두 Q의 5 / 50 / 95 백분위, Q − G의 백분위와 평균(편향), 눈금 값.
- **학습 에피소드마다 기록:** return, 그리고 가장 가까운 snapshot으로 잰 Q(z_t, a_t) − 그 에피소드 자신의 G_t.

## 4. 판정 기준

- **비교 snapshot.** 처음 1,500 update 안에서 Q(z, π(z))의 5–95 폭이 가장 큰 snapshot.
- **방향 (seed마다).** update 0 대비 Q(z, π(z))의 5–95 폭의 배율 w, 5 백분위 이동 Δlo, 95 백분위 이동 Δhi를 본다.
  - w < 1.5이면 **"벌어지지 않음"**.
  - 벌어졌고, Δhi > 0이며 Δhi가 아래쪽 이동(−Δlo의 양수 부분)의 3배 이상이면 **"위로"**.
  - 벌어졌고, Δlo < 0이며 −Δlo가 위쪽 이동(Δhi의 양수 부분)의 3배 이상이면 **"아래로"**.
  - 벌어졌는데 위 둘이 아니면 **"양쪽으로"**.
- **조건별 판정.** seed 3개 중 2개 이상이 같은 방향이면 그 방향, 아니면 "미결".
- 보고만: Q(z, a)의 같은 방향 판정, 편향(Q − G 평균)의 변화.

## 5. 예측

| | 예측 | 확률 |
|---|---|---|
| P1 | quadruped 모터 "위로" | 0.4 |
| P2 | quadruped 모터 "양쪽으로" | 0.4 |
| P3 | walker 마찰 "위로" | 0.35 |
| P4 | walker 마찰 "양쪽으로" | 0.45 |
| P5 | 두 조건 모두 비교 snapshot에서 편향(Q(z, a) − G 평균)이 update 0보다 크다 | 0.6 |

## 6. 다음 단계 규칙

| 결과 | 다음 |
|---|---|
| 두 조건 모두 "위로" | 가치 쪽 형태로 "실현 return으로 Q의 하한(또는 상한)을 묶기"를 고른다 |
| 두 조건 모두 "양쪽으로" | "critic을 먼저 안정시키기"(정책과 planner가 새 Q를 따르기 전에 Q만 학습)와 sim 데이터 균형 샘플링을 고른다 |
| 조건마다 다르거나 미결 | 두 형태를 한 설계에서 같이 시험할지 사용자에게 숫자로 묻는다 |
| "아래로" 또는 "벌어지지 않음" | Q가 아니라 정책이나 dynamics 쪽 변화가 꺼짐을 만든다는 뜻이다. 두 형태 모두 고르지 않고, 꺼짐 직후의 정책 변화를 먼저 본다(등록 안 함 표시) |

이 측정은 방법을 고르는 순서의 셋째 단계다. 앞의 두 단계(파라미터 밖 변화와 식별 기준선, SGFT 기준선)는 따로 등록한다. 이 결과만으로 방법을 확정하지 않는다.

## 7. 한계

- 조건 둘, seed 셋, 3,000 update까지만 본다.
- 고정 상태 집합은 사전학습 planner가 간 상태다. 새 정책이 가는 상태의 Q는 학습 에피소드 기록으로만 본다.
- 기준 return의 꼬리는 사전학습 Q로 bootstrap했다. 그 값 자체가 틀릴 수 있지만, 모든 snapshot에 같으므로 방향 비교에는 영향이 없다.
- 백분위는 상태 집합 위의 분포다. Q의 앙상블 불일치는 보지 않는다.

## 9. 작은 시험 (등록 전, 판정에 쓰지 않음)

`/mnt/newssd/cjkim/td/d15_smoke/`에서 quadruped 모터 seed 9를 줄여 돌렸다(수집 1,000 스텝, update 500, snapshot 250마다).

- **첫 시험은 snapshot 복사에서 멈췄다.** 모델 state dict에 텐서가 아닌 항목(torch.Size)이 있어서였다. 텐서가 아닌 항목은 그대로 복사하도록 고쳤다.
- **고친 뒤 끝까지 돈다.** snapshot 3개(update 0, 250, 500), 학습 에피소드 1개, 요약.
- **본 값(줄인 실행, 판정에 쓰지 않음).** 상태 집합을 앞 300 스텝으로 잡았던 판에서 Q(z, π(z))의 5 / 50 / 95 백분위가 update 0에서 160.5 / 188.7 / 189.9, update 250에서 157.4 / 185.9 / 187.0이었다. 편향 Q(z, a) − G는 +74.1에서 +71.2였다. update 전부터 Q가 기준 return보다 약 74 높다. 이 seed는 update 직후 에피소드가 490으로 떨어지지 않았다.
- **이 시험을 본 뒤 고친 것(등록 전).**
  - 상태 집합을 앞 300 스텝에서 50–349 스텝으로 바꿨다. 출발 구간의 낮은 Q가 기준 폭을 키워 벌어짐을 묻을 수 있어서다.
  - 판정에 "폭이 1.5배 이상 벌어졌는가"를 먼저 보는 단계를 넣었다. 처음 규칙은 분포 전체가 아래로 옮겨 간 것(폭 변화 없음)도 "아래로"로 읽었는데, 질문은 벌어진 방향이다.
