# 설계 03: 알려진 가치 쪽 처방(상상 rollout으로 가치 다시 맞추기, Q 앙상블 최솟값)이 안 풀린 셀을 푸는가 (2026-11-24 등록)

상태: 등록. 결과를 보기 전에 썼다. 결과를 본 뒤 아래 기준·팔·지표를 바꾸지 않는다. 등록하지 않은 분석에는 "등록 안 함"이라고 적는다.

## 0. 배경

- 설계 02 결과: 적은 데이터 dynamics fine-tuning의 실패 4셀 중 1셀(quadruped 마찰)은 알려진 모델 쪽 처방으로 풀렸다. 3셀(walker 마찰 0.15, quadruped 모터 0.35, cheetah 마찰 0.15)은 어떤 처방으로도 안 풀렸다. 이 3셀에서는 planner가 간 상태에서 모델이 이미 더 정확했다. 등록한 표의 다음 줄은 "가치(terminal Q) 쪽"이었다. 다만 이것은 소거로 얻은 판정이다.
- 선행 연구 확인(`prior_value_refit_ko.md`): 가치 쪽에서 이미 알려진 처방이 둘 있고, 둘 다 이 저장소와 SimDist 저장소에서 돌린 적이 없다.
  - **ReDRAW (2504.02252):** dynamics만 고친 world model 안의 상상 rollout으로 가치와 정책을 다시 배운다. 실제 reward는 쓰지 않는다.
  - **MRS.Q (2601.21306):** 정책으로 가치를 평가하는 모든 곳(TD 목표, planner의 끝 가치)에서 Q 앙상블 전체의 최솟값을 쓴다.
- **사용자 결정 (2026-11-24):** 새 방법을 만들기 전에 이 두 처방을 먼저 돌린다.
- 이 설계는 "원인이 가치 쪽"이라는 판정을 처음으로 직접 시험한다.

## 1. 질문

- **V1 (막기):** 가치 쪽 처방 팔 하나가 안 풀린 3셀 중 2셀 이상에서 실패를 막는가.
- **V2 (이득):** 가치 쪽 처방 팔 하나가 안 풀린 3셀 중 2셀 이상에서 잃은 return의 절반 이상을 되찾는가.
- **H (해):** 가치를 다시 맞추면 그 바탕 모델 팔보다 나빠지는가(SimDist 설계 22에서 본 일).
- **G (가치 일치):** 가치를 다시 맞추면 Q의 약속과 실현 return의 차이가 주는가.

## 2. 고정 설정

- 설계 02와 같은 것: 코드(공식 TD-MPC2 332f19e, 고치지 않음), 체크포인트, 환경, 6셀, 실데이터(설계 01 `data.npz`), planner 기본값, 넘어짐 정의, 동작 품질 지표, 평가(eval_mode, 평가 시드 2, 조건마다 20 에피소드).
- **안 풀린 셀 U (판정용, 고정):** walker 마찰 0.15, quadruped 모터 0.35, cheetah 마찰 0.15. 나머지 3셀은 해가 없는지 보는 데 쓴다.
- **재사용:** 설계 01의 FT-D2000 체크포인트, 설계 02의 MIX 체크포인트. 설계 02의 평가 결과(PRE, D2000, MIX, MIX+PEN1; 같은 평가 시드·에피소드 수)를 기준으로 그대로 쓴다. ρ의 분모와 PRE 넘어짐도 설계 02 값이다.
- 큰 결과 파일은 `/mnt/newssd/cjkim/td/d03/`에 둔다. 요약 표만 `research/results/d03/`에 커밋한다.

## 3. 팔

| 팔 | dynamics | Q와 정책 | planner의 끝 가치 |
|---|---|---|---|
| D2000+MIN | FT-D2000 | 사전학습 그대로 | Q 5개의 최솟값 |
| MIX+MIN | MIX | 사전학습 그대로 | Q 5개의 최솟값 |
| D2000+IMG | FT-D2000 | 상상 rollout(K = 3)으로 다시 맞춤 | 공식(무작위 2개 평균) |
| MIX+IMG | MIX | 상상 rollout(K = 3)으로 다시 맞춤 | 공식 |
| D2000+IMG15 | FT-D2000 | 상상 rollout(K = 15)으로 다시 맞춤 | 공식 |
| D2000+IMGM | FT-D2000 | 상상 rollout(K = 3)으로 다시 맞춤, TD 목표에 target Q 5개의 최솟값 | Q 5개의 최솟값 |

- **MIN (MRS.Q 방식의 planner 부분):** 계획 가치 = Σ_{t<3} γ^t r̂_t + γ³ min_i Q_i(ẑ_3, π(ẑ_3)). 공식 코드는 고치지 않고 연구 스크립트에서 agent의 가치 함수만 바꿔 끼운다.
- **IMG (ReDRAW 방식, TD-MPC2 부품으로 구현):** encoder, dynamics, reward는 얼린다. Q 5개와 정책만 학습한다.
  - 출발 상태: 실데이터 학습 10 에피소드의 상태 5,000개에서 batch 256을 고르게 뽑는다.
  - rollout: 적응한 dynamics 안에서 정책 π(표본 행동)로 K 스텝. 보상은 reward head의 기대값 r̂다. 실제 보상은 쓰지 않는다.
  - Q 손실: 공식과 같은 soft cross-entropy. TD 목표 = r̂_t + γ · (target Q에서 무작위 2개의 최솟값)(ẑ_{t+1}, π(ẑ_{t+1})). IMGM만 target Q 5개 전체의 최솟값을 쓴다. 모든 스텝에 같은 가중을 준다.
  - 정책 손실: 공식 `update_pi`를 상상한 모든 상태에 같은 가중으로 쓴다.
  - Adam lr 3e-4(정책은 공식 optimizer), grad clip 20, target Q soft update τ = 0.01, 10,000 단계, 학습 시드 11. RunningScale은 체크포인트에 없어서 새로 시작한다(설계 01 FT-A와 같음).
- **정책만 실행 (보고용):** PRE와 IMG 4팔의 정책 평균 행동을 planner 없이 바뀐 조건에서 20 에피소드 돌린다. ReDRAW는 정책을 배포하므로 참고로 본다.

## 4. 측정

- **성능 (모든 팔):** return, 넘어짐 사건/에피소드, 넘어진 스텝 비율, 부드러움, 노력, 흔들림. 회복 비율 ρ = (R_팔 − R_PRE) / (R_nom,PRE − R_PRE), 에피소드 bootstrap 95 % 구간. 평소 조건 return은 보고만 한다.
- **가치 차이 (새 6팔):** 설계 02 A2와 같은 식을 그 팔의 planner가 간 상태 200개(바뀐 조건 평가 에피소드 0, 1의 스텝 50–250)에서 잰다.
  - 그 팔의 planner로 다시 계획한 3스텝 행동열 a*
  - 예측 가치 V̂, 3스텝 실제 가치 V₃(둘 다 그 팔의 Q 5개 평균으로 끝 가치를 붙임), 실현 return G
  - 모델 부분 g_m = V̂ − V₃, 가치 부분 g_v = V₃ − G
- **모델 오차 (새 6팔, 보고용):** 그 팔의 planner가 간 상태에서 바탕 dynamics의 3스텝 수준 오차 / 사전학습의 것(κ).

## 5. 판정 기준 (실행 전 고정)

- 셀별 판정은 설계 02와 같다. "막음": ρ ≥ 0.25이고 넘어짐 증가(PRE 대비) < 0.5/에피소드. "이득": ρ ≥ 0.5이고 넘어짐 증가 < 0.5.
- **V1 "가치 쪽 처방이 막는다":** 새 6팔 중 하나가 U의 3셀 중 2셀 이상에서 "막음"이면 "그렇다"다.
- **V2 "가치 쪽 처방이 이득까지 낸다":** 새 6팔 중 하나가 U의 3셀 중 2셀 이상에서 "이득"이면 "그렇다"다.
- **H "가치를 다시 맞추면 나빠진다":** D2000+IMG가 D2000보다 나쁜 셀이 6셀 중 3셀 이상이면 "그렇다"다. "나쁘다" = ρ가 0.1 이상 낮거나 넘어짐이 에피소드당 0.5 이상 많다.
- **G "Q의 약속이 현실에 가까워진다":** U의 3셀 중 2셀 이상에서 D2000+IMG의 평균 g_v가 D2000(설계 02 측정)보다 작고, 차이의 상태 bootstrap 95 % 구간이 0 아래면 "그렇다"다.
- 보고(판정 없음): 새 6팔의 6셀 "막음"·"이득" 수를 설계 02의 기준선 MIX+PEN1(막음 3/6, 이득 3/6)과 나란히 적는다.

## 8. 한계 (미리 적음)

- 체크포인트 seed 1개, 데이터·학습 시드 각 1개다.
- IMG는 ReDRAW를 TD-MPC2 부품으로 옮긴 것이다. ReDRAW 원래 구현(Dreamer식 actor-critic, 상상 길이 40, 잔차 dynamics)과 같지 않다. 여기서 실패해도 ReDRAW 자체의 실패는 아니다.
- MIN은 MRS.Q의 planner 부분만 옮긴 것이다(Q 5개, MRS.Q는 10개). 사전학습 때 최솟값으로 배운 Q가 아니다.
- IMG의 출발 상태는 PRE planner가 바뀐 조건에서 간 상태뿐이다.
- 단계 수 10,000과 K는 각각 하나의 선택이다.
