# 설계 03: 알려진 가치 쪽 처방(상상 rollout으로 가치 다시 맞추기, Q 앙상블 최솟값)이 안 풀린 셀을 푸는가 (2026-11-24 등록)

상태: 등록. 결과를 보기 전에 썼다. 결과를 본 뒤 아래 기준·팔·지표를 바꾸지 않는다. 등록하지 않은 분석에는 "등록 안 함"이라고 적는다.

## 0. 배경

- 설계 02 결과: 적은 데이터 dynamics fine-tuning의 실패 4셀 중 1셀(quadruped 마찰)은 알려진 모델 쪽 처방으로 풀렸다. 3셀(walker 마찰 0.15, quadruped 모터 0.35, cheetah 마찰 0.15)은 어떤 처방으로도 안 풀렸다. 이 3셀에서는 planner가 간 상태에서 모델이 이미 더 정확했다. 등록한 표의 다음 줄은 "가치(terminal Q) 쪽"이었다. 다만 이것은 소거로 얻은 판정이다.
- 선행 연구 확인(`prior_value_refit_ko.md`): 가치 쪽에서 이미 알려진 처방이 둘 있고, 둘 다 이 저장소와 SimDist 저장소에서 돌린 적이 없다.
  - **ReDRAW (2504.02252):** dynamics만 고친 world model 안의 상상 rollout으로 가치와 정책을 다시 배운다. 실제 reward는 쓰지 않는다.
  - **MRS.Q (2601.21306):** 정책으로 가치를 평가하는 모든 곳(TD 목표, planner의 끝 가치)에서 Q 앙상블 전체의 최솟값을 쓴다.
- **사용자 결정 (2026-11-24):** 새 방법을 만들기 전에 이 두 처방을 먼저 돌린다.
- 이 설계는 "원인이 가치 쪽"이라는 판정을 처음으로 직접 시험한다.

## 1. 질문

- **V1 (막기):** 가치 쪽 처방 팔 하나가 안 풀린 3셀 중 2셀 이상에서 실패를 막는가.
- **V2 (이득):** 가치 쪽 처방 팔 하나가 안 풀린 3셀 중 2셀 이상에서 잃은 return의 절반 이상을 되찾는가.
- **H (해):** 가치를 다시 맞추면 그 바탕 모델 팔보다 나빠지는가(SimDist 설계 22에서 본 일).
- **G (가치 일치):** 가치를 다시 맞추면 Q의 약속과 실현 return의 차이가 주는가.

## 3. 팔

| 팔 | dynamics | Q와 정책 | planner의 끝 가치 |
|---|---|---|---|
| D2000+MIN | FT-D2000 | 사전학습 그대로 | Q 5개의 최솟값 |
| MIX+MIN | MIX | 사전학습 그대로 | Q 5개의 최솟값 |
| D2000+IMG | FT-D2000 | 상상 rollout(K = 3)으로 다시 맞춤 | 공식(무작위 2개 평균) |
| MIX+IMG | MIX | 상상 rollout(K = 3)으로 다시 맞춤 | 공식 |
| D2000+IMG15 | FT-D2000 | 상상 rollout(K = 15)으로 다시 맞춤 | 공식 |
| D2000+IMGM | FT-D2000 | 상상 rollout(K = 3)으로 다시 맞춤, TD 목표에 target Q 5개의 최솟값 | Q 5개의 최솟값 |

- **MIN (MRS.Q 방식의 planner 부분):** 계획 가치 = Σ_{t<3} γ^t r̂_t + γ³ min_i Q_i(ẑ_3, π(ẑ_3)). 공식 코드는 고치지 않고 연구 스크립트에서 agent의 가치 함수만 바꿔 끼운다.
- **IMG (ReDRAW 방식, TD-MPC2 부품으로 구현):** encoder, dynamics, reward는 얼린다. Q 5개와 정책만 학습한다.
  - 출발 상태: 실데이터 학습 10 에피소드의 상태 5,000개에서 batch 256을 고르게 뽑는다.
  - rollout: 적응한 dynamics 안에서 정책 π(표본 행동)로 K 스텝. 보상은 reward head의 기대값 r̂다. 실제 보상은 쓰지 않는다.
  - Q 손실: 공식과 같은 soft cross-entropy. TD 목표 = r̂_t + γ · (target Q에서 무작위 2개의 최솟값)(ẑ_{t+1}, π(ẑ_{t+1})). IMGM만 target Q 5개 전체의 최솟값을 쓴다. 모든 스텝에 같은 가중을 준다.
  - 정책 손실: 공식 `update_pi`를 상상한 모든 상태에 같은 가중으로 쓴다.
  - Adam lr 3e-4(정책은 공식 optimizer), grad clip 20, target Q soft update τ = 0.01, 10,000 단계, 학습 시드 11. RunningScale은 체크포인트에 없어서 새로 시작한다(설계 01 FT-A와 같음).
- **정책만 실행 (보고용):** PRE와 IMG 4팔의 정책 평균 행동을 planner 없이 바뀐 조건에서 20 에피소드 돌린다. ReDRAW는 정책을 배포하므로 참고로 본다.

## 4. 측정

- **성능 (모든 팔):** return, 넘어짐 사건/에피소드, 넘어진 스텝 비율, 부드러움, 노력, 흔들림. 회복 비율 ρ = (R_팔 − R_PRE) / (R_nom,PRE − R_PRE), 에피소드 bootstrap 95 % 구간. 평소 조건 return은 보고만 한다.
- **가치 차이 (새 6팔):** 설계 02 A2와 같은 식을 그 팔의 planner가 간 상태 200개(바뀐 조건 평가 에피소드 0, 1의 스텝 50–250)에서 잰다.
  - 그 팔의 planner로 다시 계획한 3스텝 행동열 a*
  - 예측 가치 V̂, 3스텝 실제 가치 V₃(둘 다 그 팔의 Q 5개 평균으로 끝 가치를 붙임), 실현 return G
  - 모델 부분 g_m = V̂ − V₃, 가치 부분 g_v = V₃ − G
- **모델 오차 (새 6팔, 보고용):** 그 팔의 planner가 간 상태에서 바탕 dynamics의 3스텝 수준 오차 / 사전학습의 것(κ).

## 5. 판정 기준 (실행 전 고정)

- 셀별 판정은 설계 02와 같다. "막음": ρ ≥ 0.25이고 넘어짐 증가(PRE 대비) < 0.5/에피소드. "이득": ρ ≥ 0.5이고 넘어짐 증가 < 0.5.
- **V1 "가치 쪽 처방이 막는다":** 새 6팔 중 하나가 U의 3셀 중 2셀 이상에서 "막음"이면 "그렇다"다.
- **V2 "가치 쪽 처방이 이득까지 낸다":** 새 6팔 중 하나가 U의 3셀 중 2셀 이상에서 "이득"이면 "그렇다"다.
- **H "가치를 다시 맞추면 나빠진다":** D2000+IMG가 D2000보다 나쁜 셀이 6셀 중 3셀 이상이면 "그렇다"다. "나쁘다" = ρ가 0.1 이상 낮거나 넘어짐이 에피소드당 0.5 이상 많다.
- **G "Q의 약속이 현실에 가까워진다":** U의 3셀 중 2셀 이상에서 D2000+IMG의 평균 g_v가 D2000(설계 02 측정)보다 작고, 차이의 상태 bootstrap 95 % 구간이 0 아래면 "그렇다"다.
- 보고(판정 없음): 새 6팔의 6셀 "막음"·"이득" 수를 설계 02의 기준선 MIX+PEN1(막음 3/6, 이득 3/6)과 나란히 적는다.

### 10.3 팔이 한 일 (등록한 측정, 판정 밖 요약)

- **앙상블 최솟값(MIN)은 아무것도 바꾸지 않는다.** D2000+MIN과 D2000의 return 차이는 6셀 모두 32 이하다(759/777, 547/542, 405/405, 550/582, 732/756, 24/23). MIX+MIN과 MIX도 같다(775/817, 507/485, 513/499, 805/806, 726/746, 73/92). Q 5개가 planner가 비교하는 계획들에 대해 거의 같은 순서를 낸다. 앙상블 불일치에는 실패 신호가 없다.
- **상상으로 다시 맞추기(IMG)는 cheetah 마찰에서만 D2000의 붕괴를 덜어 준다.** return 24 → 234–306(PRE 453에는 못 미침), g_v 127 → 40(IMGM은 −0.8). 넘어짐은 0이고 노력은 2.81 → 3.70–4.49로 PRE(3.72) 수준으로 돌아온다.
- **IMG는 walker 마찰과 quadruped 모터에서는 D2000보다 훨씬 나쁘다.** walker 마찰 547 → 91–272, quadruped 모터 405 → 129–331. 넘어짐 사건 수는 늘지 않지만(0.6–2.0) 넘어진 채로 있는 시간이 는다. 넘어져 있는 시간 비율: walker 마찰 PRE 0.05, D2000 0.01 → D2000+IMG 0.72, MIX+IMG 0.35, IMGM 0.38(IMG15만 0.03). quadruped 모터 PRE 0.05, D2000 0.39 → IMG 4팔 0.44–0.80. 한 번 넘어지면 못 일어난다. 사건 수만 세는 등록 판정 지표(넘어짐 증가 < 0.5)는 이 실패를 못 잡는다.
- **IMG는 평소 조건을 지키지 못한다.** 평소 조건 return, D2000 → D2000+IMG: 833 → 705, 708 → 383, 787 → 123, 546 → 462, 713 → 614, 151 → 160. MIX → MIX+IMG: 886 → 728, 879 → 426, 961 → 207, 957 → 593, 848 → 646, 627 → 695. sim 섞기로 지킨 보존(PRE의 97 % 이상)이 다시 맞추기에서 사라진다. SimDist의 "가치를 풀면 잊는다"와 같은 방향이다.
- **rollout을 길게 하면(K 15) 갈린다.** cheetah 질량 894(지금까지 모든 팔 중 최고, 이전 최고 MIX+PEN1 786), walker 질량 805. 반면 quadruped 마찰은 38로 무너진다(D2000 550, g_v 150).
- **정책만 실행(보고):** 다시 맞춘 정책이 PRE 정책보다 나은 셀은 팔에 따라 2–4/6이다. D2000+IMG 정책은 walker 마찰 69, cheetah 마찰 7로 무너진다.

### 10.4 등록 안 한 관찰

모두 등록 안 함. 이 설계의 기록만 썼고 새 실행은 없다.

- **다시 맞춘 뒤에는 planner가 같은 agent의 정책보다 못한 경우가 많다.** 안 풀린 3셀 × IMG 4팔 = 12경우 중 8경우에서 정책만 실행한 return이 planner보다 높다(예: walker 마찰 MIX+IMG 정책 476 대 planner 236, cheetah 마찰 MIX+IMG 357 대 195, quadruped 모터 D2000+IMG 327 대 271). PRE는 3셀 모두 planner가 정책 이상이다(471 대 149, 554 대 552, 453 대 365). 다시 맞춘 Q 위에서 planner가 하는 탐색이 해가 된다.
- **다시 맞춘 planner는 바탕 dynamics가 덜 정확한 상태로 간다.** κ(그 팔이 간 상태에서 바탕 dynamics 오차 / 사전학습 오차): quadruped 모터 0.31(D2000+MIN) → 1.08(IMG), 2.58(IMG15). walker 마찰 0.31 → 0.54, 1.03. 모델 부분 과대평가 g_m도 walker 마찰에서 0.75 → 5.3–15.8로 커진다.
- **다시 맞추기는 10,000 단계에서 수렴하지 않았다.** 데이터 상태의 평균 Q가 끝까지 내려가는 중이다(walker 마찰 D2000+IMG 170 → 128, 마지막 1,000 단계에도 129 → 128). 상상 보상이 스텝당 약 0.9이므로 γ 0.99에서 고정점은 90 근처다. 평가한 Q는 옛 Q와 새 Q의 중간 상태다.
- **다시 맞추기는 좁은 상태에서만 했다.** 출발 상태가 PRE planner가 간 5,000개뿐이고 rollout은 3 스텝이다(§8에 적은 한계). 평소 조건 return 붕괴(위 10.3)와 맞는다: 그 밖 상태의 Q·정책은 학습 신호 없이 변했다.
- **성공 셀에서는 Q가 비관적으로 바뀌었다.** g_v가 walker 질량 15 → −12, cheetah 질량 3 → −37이다. 그래도 MIX+IMG와 IMG15는 이 두 셀에서 "이득"을 유지했다.
- **상한을 잰 적이 없다.** ρ의 분모는 평소 조건의 PRE return이다. 안 풀린 3셀에서 ρ ≥ 0.5가 물리적으로 가능한지(바뀐 조건에서 충분히 학습한 agent의 return) 모른다. walker 마찰은 설계 02–03에서 다시 맞추지 않은 9팔이 모두 485–565에 모여 있다. 이 셀의 "안 풀림"이 방법의 실패인지 물리 한계인지 지금 기록으로는 가를 수 없다. 설계 01을 등록할 때 넣었어야 할 측정이다.

### 10.5 다음 단계 (§7 표)

- 해당 줄: V1 아니다, H 그렇다 → "가치를 다시 맞추면 해가 된다. 설계 04는 다시 맞춘 Q가 어디서 틀리는지(자기 상태, 데이터 밖 상태) 이 설계의 기록으로 가르고, 그 실패를 겨냥한 방법 하나를 선행 연구 확인 후 등록한다."
- 알려진 가치 쪽 처방 둘(MRS.Q 방식 최솟값, ReDRAW 방식 다시 맞추기)은 이 설정에서 안 풀린 3셀을 못 푼다. 기준선은 그대로 MIX+PEN1이다(막음 3/6, 6셀 모두 평소 조건 보존).
- 주의 1: §8대로 IMG는 ReDRAW 자체가 아니다. 수렴하지 않았고 좁은 상태에서만 맞췄다. "상상으로 다시 맞추기는 안 된다"가 아니라 "이 예산·이 상태 범위에서는 해가 된다"까지만 말할 수 있다.
- 주의 2: 방법을 등록하기 전에 안 풀린 3셀의 상한을 재야 한다(10.4 마지막 줄). 상한이 PRE 근처인 셀은 "이득" 대상에서 빼고 "해를 막는다"만 묻는 것이 맞다.
